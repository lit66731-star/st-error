# Error — 酒馆插件（上下文用量监控 + 剧情时间追踪）

SillyTavern 第三方扩展。入口在酒馆「扩展程序」抽屉里，作为一块**主题自适应设置块**（inline-drawer）出现，点击标题即可展开「上下文」「时间」两个分页。

## 功能

### 上下文用量监控
- 每次 AI 生成后，自动统计当前 prompt 占用的 token 数，并在面板里显示 `当前 / 上限 tokens` 与百分比。
- 带进度条：绿色正常、黄色告警（≥80%）、红色危险（≥90%）。
- **超过 80% 时弹窗提醒**，防止上下文溢出导致模型突然「失忆」。
- 统计口径与酒馆内部一致（含 token padding）。

### 剧情时间追踪（权威时间轴）
插件是**唯一权威时钟**，AI 只是被允许看时钟的叙述者：

- **每聊天独立**：时间轴存在聊天元数据（`chat_metadata`）里，不串档；每条消息绑定当时的 `第X天 HH:MM`，编辑/删除/swipe 后会自动重算回滚。
- **每轮注入时间卡**：生成前把「当前时间 + 上次场景 + 最近事件 + 规则」注入到聊天里（深度 1，靠近结尾，模型最容易看到）。
- **AI 自己报时间**：要求 AI 每轮回复开头输出 `<time>第X天 HH:MM | +时长 | 地点</time>`，插件正则解析并推进时钟；没输出就兜底 +5 分钟。**不再额外调一次模型猜时间**，零额外消耗。
- **相对时间校验**：自动抓「昨天/前天/上周…」并换算成第X天，在面板里提示核对，专治「AI 把三天前说成昨天」。
- **手动纠错**：面板可 +5m/+10m/+1h/+1d、直接设定时间、暂停自动推进；斜杠命令 `/time` `/timeset` `/timeadv`。
- **后期修改**：时间线（全部消息，不截断）每条带 ✎ 按钮，可「钉住」某条消息的时间并自动重算后续；编辑/删除/swipe 同样回滚。
- 事件日志时间线 + 冲突警告在面板内实时显示。

### 存储
- 上下文开关等设置存于酒馆扩展设置；**剧情时间轴存于聊天元数据**（跟随聊天文件保存，导出/迁移聊天会一起带走）。

## 安装

> **为什么有时点了「安装」却没有任何提示、扩展列表里也没有？** 酒馆的「安装扩展」本质是在**服务器上执行 `git clone`**，如果你的服务器在国内（阿里云/腾讯云等）连不上 GitHub，就会静默失败（无弹窗、列表里不出现）。此时请用手动安装。

### 手动安装（最可靠，推荐国内服务器）

1. 把本仓库的 `index.js`、`manifest.json`、`style.css` 三个文件放到酒馆目录：
   ```
   public/scripts/extensions/third-party/error/
   ```
   可在本机「Code → Download ZIP」下载后解压上传；服务器能访问 GitHub 时也可直接：
   ```bash
   cd /你的/SillyTavern/public/scripts/extensions/third-party/
   git clone https://github.com/lit66731-star/st-error.git error
   ```
2. 重启酒馆（或刷新页面），在「扩展」列表勾选 **Error** 启用。

### 扩展面板安装（需服务器能访问 GitHub）

1. 酒馆「扩展 → 安装扩展（Install Extension）」粘贴 URL：
   ```
   https://github.com/lit66731-star/st-error
   ```
   只粘贴这一行，不要带空格、引号、换行或句尾标点，否则报 `Bad Request`。
2. 扩展列表勾选 **Error** 启用，刷新。

## 说明

- 剧情时间**不再额外调用模型**：靠解析 AI 自己输出的 `<time>` 块推进，零额外额度消耗。
- 本扩展 `auto_update` 已开启：酒馆检测到新版本并更新后，会自动刷新页面应用新版本（无需手动刷新）。

## 更新记录

- **1.3.1**：修复三处——① 上下文统计改用 `getMaxContextTokens()`（真实模型上下文，不再用旧版写死的 2048），并加 `lastPromptCounted` 兜底标记：即使精确 prompt 事件缺失/没触发，`GENERATION_ENDED` 也总会退化为聊天文本统计，不再「统计不到」；② 时间线改为**直接从消息派生**（不再有 30 条的截断），默认限高可滚动、点「展开全部」看全；③ 支持**后期修改**：时间线每条消息带 ✎ 按钮，点开可把该条消息的时间「钉住」，后续自动重算（编辑/删除/swipe 同样回滚）。
- **1.3.0**：时间功能按「权威时间轴」架构重写——时间轴存聊天元数据（每聊天独立 + 消息级绑定），每轮注入时间卡，解析 AI 输出的 `<time>` 块推进时钟，相对时间校验，事件日志时间线，斜杠命令，编辑/删除/swipe 自动回滚。不再额外调用模型。
- **1.2.0**：修复两个功能在部分酒馆版本下不触发的问题——时间追踪改为只挂在通用的 `GENERATION_ENDED` 事件上；上下文统计在旧版酒馆缺少精确事件时自动退化为「聊天文本估算」。面板新增状态行 + 「立即统计」按钮，失败不再静默。
- **1.1.2**：设置块改为**自适应酒馆主题**（不再写死白底黑字），全部改用酒馆主题变量（`--SmartTheme*` 等），浅色/深色/自定义主题下自动匹配。
- **1.1.1**：修复从 `script.js` 导入 `getContext`（它并不从该文件导出）导致的插件整体加载失败——设置块不出现的问题。改为从 `st-context.js` 导入。
- **1.1.0**：首次发布（上下文用量监控 + 剧情时间追踪，入口在扩展程序抽屉）。
